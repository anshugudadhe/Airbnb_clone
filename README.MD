# 🏡 Airbnb Clone – MERN Stack Project

A full-stack Airbnb clone built using the **MERN Stack**, designed to replicate core features of Airbnb such as property listings, user authentication, reviews, maps, and image uploads.

This project demonstrates real-world backend and frontend concepts including authentication, authorization, database relationships, cloud services, and responsive UI design.

---

## 🚀 Features

- 🔐 User Authentication & Authorization (Passport.js)
- 🏠 Property Listings (Create, Read, Update, Delete)
- 🖼 Image Upload & Storage using Cloudinary
- 🗺 Interactive Maps using Mapbox
- ⭐ Reviews & Ratings System
- ⚠ Flash Messages & Centralized Error Handling
- 📱 Responsive UI (Mobile & Desktop)
- ☁ MongoDB Atlas Cloud Database
- 🗄 Session Management with MongoDB Store
